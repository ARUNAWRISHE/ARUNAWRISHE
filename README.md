# 🚀 FEATURED PORTFOLIO PROJECTS

### 🔥 1. AI Ad Studio — *Autonomous Video Ad Creation Platform*

> An end-to-end AI-powered platform that ingests product/website URLs, extracts market intelligence, writes nano-level ad scripts, generates video storyboards, synthesizes voiceovers, and renders high-converting video ad creatives automatically.

```
┌──────────────┐     ┌──────────────────┐     ┌──────────────────────┐
│ Website URL  │ ──> │ Web Scraper &    │ ──> │ AI Intelligence &    │
│ & Metadata   │     │ Intelligence Engine    │ Script Generator     │
└──────────────┘     └──────────────────┘     └──────────────────────┘
                                                              │
┌──────────────┐     ┌──────────────────┐     ┌───────────────v──────┐
│ Final Campaign│ <── │ Video Timeline & │ <── │ Storyboard & Voice  │
│ Export (.MP4)│     │ Render Engine    │     │ Audio Synthesizer    │
└──────────────┘     └──────────────────┘     └──────────────────────┘
```

**Technical Highlights:**
- **Frontend:** Next.js 14, React, Tailwind CSS, Framer Motion
- **Backend:** FastAPI (Python), Async Task Pipelines, Celery/Redis
- **AI & Media:** LLM Prompt Chains, Voice Synthesis Engine, FFmpeg Video Processing
